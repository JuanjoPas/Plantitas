# Imágenes de Plantitas

Este directorio contiene únicamente copias optimizadas para la web. Las fotografías originales se conservan fuera del repositorio.

## Formato obligatorio

- Formato: WebP.
- Lado mayor: máximo 1600 px, sin ampliar imágenes pequeñas.
- Calidad orientativa: 82 %.
- Metadatos EXIF: eliminados para reducir tamaño y proteger datos privados.
- Tamaño recomendado: entre 150 y 400 KB por fotografía.
- Si una imagen clínica necesita más detalle, puede superar ese tamaño de forma justificada.

## Organización

- `plantas/<identificador>/`: fotografías generales de cada ejemplar.
- `plantas/<identificador>/plagas/`: primeros planos de plagas o enfermedades.
- `casa/`: fotografías de habitaciones, ventanas y condiciones ambientales.

## Nombres

Usar minúsculas, guiones y fecha ISO:

`2026-08-02-vista-general-01.webp`

`2026-08-02-cochinilla-tallo-01.webp`

No se deben subir aquí fotografías originales en JPEG, HEIC o PNG.
