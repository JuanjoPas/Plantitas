# Imágenes de la casa

Fotografías WebP utilizadas para documentar luz, ubicación y condiciones ambientales de las plantas.

## Convención de nombres

`AAAA-MM-DD-estancia-zona-numero.webp`

Ejemplos:

- `2026-08-02-comedor-fondo-01.webp`
- `2026-08-02-galeria-ventana-01.webp`
- `2026-08-02-habitacion-alba-david-fondo-01.webp`
